# Modélisation de la Volatilité GARCH
Implémentation complète de modèles ARCH/GARCH pour la modélisation de la volatilité conditionnelle, appliquée aux données de JPMorgan Chase. 
## Méthodes
- Test ARCH-LM (Engle) - Modèle ARCH(1) - Modèle GARCH(1,1) — estimation, diagnostics, prévision - Modèle EGARCH — effet de levier et asymétrie - Comparaison de modèles (AIC/BIC) 
## Outils Python
· arch · NumPy · Pandas · Matplotlib · SciPy
